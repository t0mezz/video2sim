Our code is MIT (`LICENSE`, added 2026-11-03) and covers our files only. Third-party terms travel with their components regardless of our license, and hosted-service terms bind independently. Everything below cannot be folded into one MIT license.

Distribution consequences (researched against primary sources 2026-11-03): permissive libraries (MIT/BSD/Apache-2.0/PSF-2.0) are redistributable, but Apache-2.0 §4 still requires shipping the license text, marking modified files, and keeping notices ([Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0)). The installed tree contains no GPL/LGPL/AGPL or non-commercial code, so no copyleft burden exists; the only NC licenses encountered left with the dropped TRELLIS.2 path (D-018). `certifi` (MPL-2.0, transitive) is file-level copyleft only and permits unmodified use in larger works ([MPL 2.0 FAQ Q8/Q11](https://www.mozilla.org/en-US/MPL/2.0/FAQ/)). Publications acknowledge SAM (§1(b)(ii)); end-use bans stand (§1(b)(v)). Source: [facebookresearch/sam3 LICENSE](https://raw.githubusercontent.com/facebookresearch/sam3/main/LICENSE). Lawyer review is required before commercial use or redistribution of scenes with SAM-derived geometry (D-005 scope is research). A `THIRD-PARTY-NOTICES` file with required texts is still open.
